# نظام الموارد البشرية — HR Management System

نظام موارد بشرية عربي (RTL) متعدد الشركات والفروع، مبني بـ **ASP.NET Core MVC** و **PostgreSQL**.
يدير الموظفين والتحضير والإجازات والرواتب والعقود والسلف، مع صلاحيات تفصيلية حسب الشركة والفرع.

> هذه نسخة عرض (Portfolio). كل البيانات فيها **وهمية** ويولّدها الـ Seeder تلقائياً.

An Arabic-first, multi-company HR system built with ASP.NET Core MVC and PostgreSQL.
This is a portfolio edition: all data is fictional and generated by the seeder.

---

## المزايا

| الخدمة | ماذا تقدم |
|---|---|
| **لوحة التحكم** | مؤشرات عدد الموظفين ونسبة السعودة والحضور وتكلفة الرواتب، رسوم بيانية، وتنبيهات بانتهاء الإقامات والهويات والعقود |
| **الموظفون** | ملف كامل (شخصي، مالي، وظيفي، وثائق)، استيراد من Excel، فلاتر، طباعة كشوفات، حالات الموظف |
| **التحضير** | كشف يومي حسب الفرع مع احتساب التأخير تلقائياً، وملخص شهري بنسبة الحضور |
| **الإجازات** | 9 أنواع إجازات وفق نظام العمل السعودي، اعتماد ورفض وإلغاء، رصيد سنوي يُخصم ويُسترجع تلقائياً |
| **السلف** | سقف للسلفة، أقساط شهرية تُخصم تلقائياً من مسير الرواتب |
| **العقود** | إصدار وتجديد وإنهاء، ترقيم تلقائي، وطباعة عقد عربي بصيغة A4 |
| **مسيرات الرواتب** | احتساب الغياب والتأمينات الاجتماعية (GOSI) والسلف، مسودة ← معتمد ← مصروف، قسائم رواتب، وملف تحويل بنكي |
| **الصلاحيات** | أدوار قابلة للتخصيص لكل خدمة (عرض، إضافة، تعديل، حذف، اعتماد)، ونطاق عام / شركة / فرع |
| **أخرى** | سجل الدخول وسجل النشاطات، تذاكر الدعم، واجهة عربية/إنجليزية، تخصيص الألوان |

## التشغيل

المتطلبات: .NET 10 SDK، PostgreSQL (أو Docker)، Node.js (اختياري لبناء CSS).

```bash
# 1) قاعدة البيانات (أو استخدم PostgreSQL مثبت عندك)
docker compose up -d db

# 2) أنشئ ملف appsettings.Local.json بجانب appsettings.json (لا يُرفع على GitHub):
#    { "ConnectionStrings": { "DefaultConnection": "Host=localhost;Port=5432;Database=hr_demo;Username=postgres;Password=YOUR_PASSWORD" } }

# 3) الجداول والبيانات التجريبية
dotnet tool install --global dotnet-ef   # مرة واحدة فقط
dotnet ef database update
dotnet run -- seed

# 4) التشغيل
dotnet run
```
